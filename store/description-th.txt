ดูเว็บของคุณแบบที่มือถือแสดงจริง รวมถึงจอพับรุ่นใหม่

กดไอคอน Foldframe บนแท็บไหนก็ได้ หน้าเว็บจะเปิดในกรอบเครื่อง ด้วยขนาด CSS viewport ตรงตามรุ่นที่เลือก

มีอะไรบ้าง
• มือถือ แท็บเล็ต และจอพับรุ่นปัจจุบันราว 20 รุ่น ขนาดจอตรงตามเครื่องจริง
• จอพับแสดงได้ทั้งตอนกางและตอนพับ พร้อมรอยพับ เห็นทันทีว่าเนื้อหาไหนตกรอยพับ
• สลับแนวตั้ง/แนวนอนได้ในคลิกเดียว
• กำหนดความกว้างและความสูงเองได้
• ย่อให้พอดีหน้าต่าง หรือดูขนาดจริง 100%
• คีย์ลัด: R หมุนจอ, F กาง/พับ, Z ซูม
• ใช้กับ localhost และ dev server ในเครื่องได้
• ธีมมืด/สว่าง ภาษาไทยและอังกฤษ

เน้นความเป็นส่วนตัว
• ไม่ต้องสมัคร ไม่มีโฆษณา ไม่มี analytics ไม่ส่งข้อมูลไปไหน
• ขอสิทธิ์ทีละเว็บ เฉพาะตอนพรีวิว
• แก้ header เฉพาะในแท็บพรีวิวของตัวเอง แท็บปกติไม่ได้รับผลกระทบ

ขนาดหน้าจออ้างอิงจากฐานข้อมูลอุปกรณ์สาธารณะ และจะอัปเดตเมื่อมีเครื่องรุ่นใหม่ออกมา
